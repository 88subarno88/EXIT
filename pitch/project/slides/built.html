Built to keep running

The site never calls an API when a page loads.

  • Everything is computed once a day and served from SQLite, so a source going down cannot take the site with it
  • Every CoinMarketCap call is logged — endpoint, status, latency, credits — and the log is a public page
  • Tokens are keyed by CoinMarketCap id, never by symbol, because symbols collide and corrupt silently
  • A public JSON API, rate limited, always returning the as_of stamp of the data
The architecture rule is one line: the web app reads SQLite and nothing else. That is what lets the demo survive the API tier lapsing. The data log is also the evidence of real API usage, which is worth more as a live page than as a claim in a README.
